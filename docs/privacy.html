Privacy Policy

AutoSchedulerSM · Last updated: November 25, 2026

AutoSchedulerSM ("the app") is a private tool used only by its owner to publish the owner's own content to the owner's own Facebook Page, Instagram account, TikTok account and YouTube channel. It has no other users.

YouTube API Services

YouTube This app uses YouTube API Services

The app uses YouTube API Services to upload videos to the owner's YouTube channel and to read the connected channel's name. By using the app, you agree to be bound by the YouTube Terms of Service. Information accessed through YouTube API Services is also subject to the Google Privacy Policy (https://policies.google.com/privacy).

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Information the app accesses, collects and stores

  • OAuth tokens issued by Google (YouTube), Meta and TikTok for the owner's own accounts. A long-lived refresh token is stored in the owner's private Google Sheet or as an encrypted GitHub Actions secret. Short-lived access tokens are used during a run and never stored.
  • Basic channel/account information (channel or account name and ID), used only to confirm which account is connected.
  • The owner's own content (videos, photos, captions, titles, scheduled times) that the owner places in their private Google Sheet and Google Drive.
  • Links to published posts (for example the YouTube video link), written back to the owner's private Google Sheet.

The app does not access, collect or store any other users' data, YouTube viewing data, comments, analytics or private channel data.

How information is used

Information is used only to upload the owner's scheduled content to the owner's own accounts at the scheduled time and to report the result to the owner.

Sharing

Information is not sold, rented, or shared with any third party, and is not used for advertising. Content is sent only to the platform it is being published to (for example, videos to YouTube).

Cookies and browser storage

The website does not use cookies or tracking. The "Connect YouTube" and "Connect TikTok" pages store the app's public client ID in the browser's local storage, on the owner's own device, only so it does not have to be typed again. It can be cleared at any time by clearing the browser's site data.

Data retention and deletion

  • Stored tokens are kept until access is revoked or the owner deletes them.
  • Revoke YouTube/Google access at any time from the Google security settings page: https://myaccount.google.com/permissions. After revocation the app can no longer access the YouTube channel.
  • Revoke Facebook/Instagram access in Facebook Settings → Business integrations, and TikTok access in TikTok Settings → Security → Manage app permissions.
  • To delete all stored data, revoke access as above and delete the stored tokens from the Google Sheet ("_state" tab) and the GitHub repository secrets. Deletion takes effect immediately.
